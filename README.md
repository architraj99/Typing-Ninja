# Typing Ninja

Typing  Ninja is a simple typing game made with HTML, CSS and JavaScript......

Words fall from the top of the screen 
and you have to type them before they reach the bottom......

You get 3 lives....

. If a word reaches the bottom ... you lose one life

## Controls

* click on Enter to  Start game
* Type on your keyboard to destroy words....
* Backspace to Fix typing mistakes
* Esc to  Pause / Resume
* R  Restart after GAME OVER

The game is completely keyboard controlled.....
NO MOUSE NO TAB 

## Features

* THE WORDS FALL RANDOMLY FROM THE SKY....
* YOU GET IN TOTAL 3 LIVE....
* ALSO YOU CAN SEE THE LIVE WPM
* IT ALSO SHOW'S THE ACCURACY
* ITS A GAME SO, IT HAVE SCORE TOO!!!
* DIFFICULTY INCREASES AS YOU GO FURTHER
* ALSO THERES AND OPTION TO PAUSE OR RESUME THE GAME

NOTE - As the level increases, words start falling faster and new words appear more often.
